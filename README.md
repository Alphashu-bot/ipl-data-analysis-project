
# IPL / Cricket Data Analytics with Custom Performance Metrics

## 📌 Project Overview
This project performs in-depth analysis of IPL (Indian Premier League) cricket data to evaluate player and team performance using both traditional statistics and **custom-designed performance metrics**.

The aim is to go beyond averages and strike rates by introducing advanced metrics that better quantify consistency, impact, and efficiency.

---

## 🎯 Objectives
- Analyze IPL player and team performance
- Design advanced cricket performance metrics
- Identify consistent and high-impact players
- Visualize trends and insights from match and ball-by-ball data

---

## 📊 Dataset Description
The dataset includes:
- Match-level data
- Ball-by-ball delivery data
- Player statistics (runs, balls, wickets, overs, etc.)
- Team-level performance information

---

## 📐 Custom Metrics Designed

### 🔹 Consistency Index
Measures how reliably a player performs across matches.
